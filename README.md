📚 Intelligent Book Recommender System

An ML-based Book Recommendation System that recommends similar books based on their content.

🚀 Features

- Recommends books similar to the selected book
- Uses NLP for text processing
- Uses TF-IDF Vectorization to convert text into numerical features
- Uses Cosine Similarity to find similar books
- Interactive web interface using Streamlit

🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- NLP
- Streamlit

⚙️ How It Works

Book Data
   ↓
Text Processing
   ↓
TF-IDF Vectorization
   ↓
Cosine Similarity
   ↓
Similar Books
   ↓
Recommendations

▶️ Run the Project

Install the required libraries:

pip install -r requirements.txt

Run the application:

streamlit run app.py
